# Canonical contract resources

The [resource manifest](manifest.json) defines the identities, versions, owners and visibility of the packaged schemas, protocols and fixtures. Remote owns the public operation registry and supplies the reviewed [OpenAPI handoff](api/README.md). Contracts owns the deterministic generation and packaging of the published resources.

Start with the contract reference in [English](../docs/en/contract-reference.md) or [Vietnamese](../docs/vi/contract-reference.md). It maps the schema families, RPC and NCAP formats, and [public compatibility anchors](compatibility/README.md). Use the standalone verification guides for [Python and the public SDK](../docs/en/verification.md) and [Rust](../docs/en/native.md).

The [former monorepo workflow](../docs/en/history/archive/monorepo-contracts-workflow.md) records the original generation and integration procedure.
