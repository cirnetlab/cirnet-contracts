# Canonical contract resources

The [resource manifest](manifest.json) defines the contract identities, versions, owners, visibility and projection paths used by the native source tree. The [compatibility baselines](compatibility/README.md) preserve historical schema and wire evidence. Remote owns operation registration and supplies the reviewed [OpenAPI handoff](api/README.md). Contracts owns the generation and packaging of shared resources.

See the contract reference in [English](../docs/en/contract-reference.md) or [Vietnamese](../docs/vi/contract-reference.md) and the [native verification guide](../docs/en/native.md).
