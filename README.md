# CIRNET Contracts

Canonical CircuitGraph schemas, device catalogs, Hardware RPC and NCAP for CIRNET Lab. The Rust crate validates resources and encodes the supported wire formats. The TypeScript SDK provides public DTOs and offline validation.

[Documentation](docs/en/index.md) · [Tài liệu tiếng Việt](docs/vi/index.md)

Version `0.3.0-dev.1` is the first development version of this repository generation. The [source baseline](https://github.com/cirnetlab/cirnet-contracts/tree/dbbb19aee61cab39a89319e76c19bb8909629355) identifies the verified implementations migrated here. Remote selects integrated candidates.
